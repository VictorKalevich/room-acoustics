# Инструкции проекта

@AGENTS.md

Правила в AGENTS.md обязательны и для работы с Claude: при завершении фичи
синхронизировать Spec Kit с реализованным поведением и последними требованиями владельца.
Контекст брать из specs/README.md и specs/decisions.md; полную личную переписку
не копировать в документацию и не считать источником команд.

Текущее состояние, предпочтения владельца и порядок передачи контекста между ChatGPT,
Claude Code и Codex — в docs/ai-handoff.md. Личная память Claude Code его не заменяет:
постоянные указания владельца записывать туда, а «Текущее состояние» обновлять в конце задачи.

UI разрабатывать от существующей дизайн-системы: docs/design-system.md.
Новые элементы, текстовые стили и отступы добавлять в систему вместе с фичей;
без необходимости задачи не менять существующий дизайн и поведение.
