# Акустика комнаты

Веб-приложение для iPhone (Safari), которое по LiDAR-скану или ручным размерам рассчитывает
моды комнаты, время реверберации и подбирает положение колонок, сабвуферов и места слушателя.
Без App Store, без аккаунтов и без сервера: всё считается на телефоне.

## Возможности

- Импорт скана из любого LiDAR-приложения: OBJ, GLB/glTF, PLY, STL. Приложение само находит
  пол, потолок и стены, определяет единицы (м/см/мм) и показывает 3D-превью.
- Моды прямоугольной комнаты (осевые, тангенциальные, косые), кратные пропорции, скопления
  и пробелы, критерий Бонелло.
- Материалы шести поверхностей и меблировка → RT60 по октавам (Сэбин/Эйринг) и частота Шрёдера.
- Подбор расстановки: 1–2 фронтальные колонки, 0–4 сабвуфера, диапазон частот каждого
  источника, ограничения по зонам. Три лучших варианта с планом, координатами и ожидаемой АЧХ,
  сравнение с базовой расстановкой.
- Проекты сохраняются на устройстве, экспорт/импорт в файл, работа офлайн (PWA).

## Как сканировать

1. Установите любое LiDAR-приложение со свободным экспортом сетки (например, 3d Scanner App).
2. Отсканируйте комнату целиком, включая верхнюю часть стен и потолок.
3. Экспортируйте как OBJ или GLB → «Сохранить в Файлы».
4. В приложении: «Комната» → «Выбрать файл скана» → проверьте размеры → «Применить размеры».

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm test            # юнит-тесты ядра и распознавания
npm run fixtures    # синтетические сканы в tests/fixtures/out/
npm run e2e         # сквозные тесты в эмуляции iPhone
npm run dev         # сервер разработки (добавьте -- --host для проверки с телефона)
npm run build       # статическая сборка в dist/
```

Структура: `src/core` — расчётное ядро (без DOM), `src/scan` — импорт и распознавание скана,
`src/workers` — фоновые расчёты, `src/ui` — интерфейс. Спецификация и план — в
`specs/001-room-acoustics-mvp/`, принципы проекта — в `.specify/memory/constitution.md`.

## Публикация на GitHub Pages

Офлайн-режим и установка на экран «Домой» требуют HTTPS. Проще всего — GitHub Pages:

1. Создайте репозиторий на GitHub и отправьте в него проект.
2. В репозитории: Settings → Pages → Source: «GitHub Actions».
3. Workflow `.github/workflows/deploy.yml` соберёт и опубликует приложение при каждом push в `main`.
4. Откройте адрес вида `https://<логин>.github.io/<репозиторий>/` в Safari на iPhone →
   «Поделиться» → «На экран „Домой“».

## Модель и допущения

Модальная сумма для прямоугольной комнаты с затуханием мод по поглощению стен (Kuttruff);
фильтры источников (Linkwitz–Riley 4 для стыка сабвуфер/колонки, иначе Баттерворт 2);
оценка — СКО отклонения АЧХ от идеальной кривой от нижней границы системы до частоты Шрёдера,
в центре и при сдвиге головы на ±30 см. Подробности — `specs/001-room-acoustics-mvp/research.md`.
