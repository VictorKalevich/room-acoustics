# Акустика комнаты

Веб-приложение для iPhone (Safari), которое по LiDAR-скану или ручным размерам рассчитывает
моды комнаты, время реверберации и подбирает положение колонок, сабвуферов и места слушателя.
Без App Store, без аккаунтов и без сервера: всё считается на телефоне.

## Возможности

- Импорт скана из любого LiDAR-приложения: OBJ, GLB/glTF, PLY, STL. Приложение само находит
  пол, потолок и стены, определяет единицы (м/см/мм) и показывает 3D-превью.
- Моды прямоугольной комнаты (осевые, тангенциальные, косые), кратные пропорции, скопления
  и пробелы, критерий Бонелло.
- Материалы шести поверхностей, окна, двери и обстановка → RT60 по октавам (Сэбин/Эйринг) и частота Шрёдера.
  Обстановка подобрана по замерам сотен жилых комнат (≈ 0,5 с на средних частотах, ≈ 0,9 с на 50 Гц);
  вклад окон, проёмов и ловушек в затухание каждой моды зависит от их места (пучность или узел моды).
- Подбор расстановки: 1–2 фронтальные колонки, 0–4 сабвуфера, диапазон частот каждого
  источника, ограничения по зонам. Три лучших варианта с планом, координатами и ожидаемой АЧХ,
  сравнение с базовой расстановкой.
- Ручная расстановка: колонки, сабвуферы и слушатель перетаскиваются пальцем; тепловая карта
  лучших мест слушателя или лучших мест сабвуфера (цифровой subwoofer crawl).
- Несколько мест прослушивания (диван), запретные зоны (двери, окна, мебель), герметичность комнаты.
- Настройка сабвуфера в пределах его регулировок: задержка (если есть), фаза 0/180°, плавная 0–180°
  или 0–360°, уровень, частота кроссовера.
- Эквалайзер: фильтры-срезы с экспортом в Equalizer APO, REW и miniDSP (48/96 кГц).
- Акустическая обработка: точки первых отражений, басовые ловушки для самых сильных пиков.
- Импорт замера REW (txt), сравнение с моделью и подстройка модели под замер.
- Варианты расстановки и их сравнение.
- Сложная планировка: в скане можно выбрать основную комнату (рамка поверх вида сверху);
  приложение находит проёмы до пола и коридор за аркой. Коридор и проёмы можно задать вручную.
- Звуковое поле в 3D («Анализ» → «Поле 3D»): где выбранные частоты гудят (красный) и проваливаются
  (синий) при текущей расстановке; показ по одной частоте, средней энергией или полосой; порог ±3/6/9/12 дБ;
  срез сверху в слое «от … до …» по высоте с перетаскиванием колонок и сабвуферов; режим «форма моды».
- Меню ☰ слева: «Измерения» (свип с калибровкой USB-микрофона, RT60 хлопком, живой анализатор баса,
  сравнение и импорт REW), «Место для записи», «Отчёт» (печать / PDF), «Импорт и экспорт»
  (через Файлы / iCloud Drive), «Помощник и словарь».
- «Анализ» → «Обзор»: оценка комнаты 0–100, список проблем с переходами к решению, время затухания мод.
- Тон любой моды через систему (кнопка ▶) и мини-плеер.
- Мебель из размеченного скана — сразу запретные зоны; памятка по сканированию и проверка файла.
- План обработки (ловушки, панели, облака) с расчётом «что если»; FIR-фильтры; прослушивание в наушниках.
- PEQ и all-pass для каждого сабвуфера, схема DBA, устойчивость расстановки; ниша и скос потолка.
- Волновая модель (FDTD) для комнаты с коридором: учитывает реальную глубину коридора, его стены
  и открытые концы. Показывает моды системы «комната + коридор» и используется в подборе
  расстановки, тепловых картах, настройке сабвуфера, эквалайзере и подстройке под замер.
- Проекты сохраняются на устройстве, экспорт/импорт в файл, работа офлайн (PWA).

## Навигация

Основные разделы: **Комната → Анализ → Расстановка → Настройка**.

- В комнате: геометрия и скан, материалы, проёмы, зоны. Группы можно свернуть.
- В анализе: обзор, список мод, поле 3D.
- В расстановке: общий блок «Система и цель подбора», затем автоматический или ручной режим.
- В настройке: сабвуфер, эквалайзер, обработка.
- В измерениях через меню: свип, хлопок, анализатор, сравнение и REW.

Выбранный подраздел запоминается при переходах. Импортированный замер остаётся общим
для сравнения и эквалайзера. Старые ссылки на моды, 3D и ручную расстановку поддерживаются.
Границы UI и расчётов, правила сохранения состояния и проверки описаны в [docs/ui-refactor.md](docs/ui-refactor.md).

На графиках вокала и расстановки есть независимые настройки сглаживания и психоакустический
режим. Они меняют только отображение, сохраняя прежние карты и оценки.
Подробнее: [docs/ui-smoothing.md](docs/ui-smoothing.md).

В «Месте для записи» доступны цели карты **Ровнее спектр** и **Меньше комнаты**.
Ровность спектра, вклад отражений относительно прямого голоса и RT60 показаны отдельно.
Формулы и частотная детализация сохранены: [docs/voice-metrics.md](docs/voice-metrics.md).

## Как сканировать

1. Установите любое LiDAR-приложение со свободным экспортом сетки (например, 3d Scanner App).
2. Отсканируйте комнату целиком, включая верхнюю часть стен и потолок.
3. Экспортируйте как OBJ или GLB → «Сохранить в Файлы».
4. В приложении: «Комната» → «Выбрать файл скана» → проверьте размеры → «Применить размеры».
5. Если в скан попало лишнее (коридор, соседняя комната), перетащите стороны рамки на стены
   основной комнаты. Найденные арку и коридор можно учесть галочкой.

## Разработка

Требуется Node.js 20+.

```bash
npm install
npm test            # юнит-тесты ядра и распознавания
npm run fixtures    # синтетические сканы в tests/fixtures/out/
npm run lint        # линтер (oxlint, предупреждения = ошибки)
npm run e2e         # сквозные тесты в эмуляции iPhone (Chromium)
npm run e2e:safari  # то же в Safari/WebKit (первый раз: npx playwright install webkit)
npm run dev         # сервер разработки (добавьте -- --host для проверки с телефона)
npm run build       # статическая сборка в dist/
```

Структура: `src/core` — расчётное ядро (без DOM), `src/scan` — импорт и распознавание скана,
`src/workers` — фоновые расчёты, `src/ui` — интерфейс. Спецификации и планы — в
[индексе Spec Kit](specs/README.md), актуальное поведение — в
[specs/current-state.md](specs/current-state.md), принципы — в
[конституции](.specify/memory/constitution.md), решения — в [журнале](specs/decisions.md).

При завершении каждой фичи обновляются Spec Kit и связанные документы, если задача
дополняет или заменяет прежние требования. Правило закреплено в [AGENTS.md](AGENTS.md)
и [CLAUDE.md](CLAUDE.md). Обсуждаемые, но не реализованные идеи отмечены отдельно
в [specs/deferred.md](specs/deferred.md).

## Публикация на GitHub Pages

Офлайн-режим и установка на экран «Домой» требуют HTTPS. Проще всего — GitHub Pages:

1. Создайте репозиторий на GitHub и отправьте в него проект.
2. В репозитории: Settings → Pages → Source: «GitHub Actions».
3. Скопируйте `deploy/github-pages.yml` в `.github/workflows/deploy.yml` — workflow соберёт
   и опубликует приложение при каждом push в `main`.
4. Откройте адрес вида `https://<логин>.github.io/<репозиторий>/` в Safari на iPhone →
   «Поделиться» → «На экран „Домой“».

## Модель и допущения

Модальная сумма для прямоугольной комнаты с затуханием мод по поглощению стен (Kuttruff);
фильтры источников (Linkwitz–Riley 4 для стыка сабвуфер/колонки, иначе Баттерворт 2);
оценка — СКО отклонения АЧХ от идеальной кривой от нижней границы системы до частоты Шрёдера,
в центре и при сдвиге головы на ±30 см. Подробности — `specs/001-room-acoustics-mvp/research.md`.

Если есть коридор или ниша, расчёт идёт волновой моделью: явная схема FDTD на кубической сетке
(шаг ≈ c/(10·fmax)), поглощение граней не зависит от частоты (среднее по 63–250 Гц),
открытые концы коридора и проёмы почти полностью поглощают. В волновой модели АЧХ слушателя
считается в одной точке (без сдвига головы), подстройка под замер меняет только затухание.
Время на настольном компьютере (комната 5×4 м и коридор 1,2 м): оценка расстановки ≈ 1 с,
карта мест сабвуфера ≈ 0,2 с, карта мест слушателя ≈ 5 с, автоподбор ≈ 13 с; на iPhone
примерно в 1,5–2 раза дольше. Подробности — `specs/003-openings-wave-model/research.md`.
