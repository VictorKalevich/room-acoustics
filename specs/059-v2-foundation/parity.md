# 059. Сохранение функциональности: legacy → v2 (V2-059)

Часть [спецификации v2](spec.md). Сверка 28.11.2026 по экранам `src/ui/screens/` и модулям ядра, которые v2 не подключает. Действующее приложение (legacy) не изменено и остаётся основным. v2 с 28.11.2026 опубликована рядом, по адресу `/v2/` (D60), а заменит legacy только по отдельному решению владельца (R59). Поэтому пробелы ниже — условие этой замены, а не потеря функциональности сейчас.

Статусы:

- **есть** — функция доступна в v2;
- **частично** — доступна, кроме названной части;
- **нет** — в v2 отсутствует.

Физическая приёмка измерений не учитывается ни для legacy (052–058), ни для v2 (V2-057).
