## Регрессионные проверки

После изменений повторяются: `npm ci`, `npm run lint`, `npm test`, `npm run build`, `npm run build:v2`, `npm run e2e:v2`, `npm run e2e`, `npm run e2e:safari`; дополнительно для v2 — `npm run e2e:v2:safari` (WebKit-эмуляция, известные расхождения — в отложенном). Результаты сравниваются с контрольным прогоном: число тестов legacy и их исход не должны ухудшиться; новые тесты v2 считаются отдельно.

## Изоляция production

- `deploy.yml`: `deploy` и артефакт Pages — только при `refs/heads/main`; права на Pages — только у `deploy`.
- `v2-check.yml`: только `contents: read`, без окружений и деплоя.
- push в `redesign/v2` не запускает `deploy.yml` (триггер — только `main`).
- Окружение `github-pages` разрешает только `main` (проверено чтением API).

## Запуск обеих оболочек

- `npm run dev` (5173) и `npm run dev:v2` (5174) работают одновременно.
- `npm run build` → `dist/` с service worker и манифестом legacy; `npm run build:v2` → `dist-v2/` без них.
- e2e legacy (4173) и smoke v2 (4174) используют разные серверы.

## Готовность будущих этапов

Пакет этапа принимается, когда:

- реализованы его задачи в согласованном объёме и обновлён Spec Kit (spec, tasks, acceptance, индекс, решения, ai-handoff);
- полный регрессионный прогон legacy не хуже контрольного, новые тесты проходят;
- для расчётных изменений — эталонные проверки и тесты эквивалентности прежних расчётов;
- для хранения — тесты миграций, повторного запуска, повреждённых данных и квот; legacy-хранилище не изменено;
- для UI — проверки на 320, 390 и 1440 px и промежуточных ширинах, клавиатура, контраст, safe-area;
- для измерений — физическая проверка на iPhone отдельно от автотестов; эмуляция WebKit не засчитывается;
- нет публикации без отдельного разрешения владельца.
