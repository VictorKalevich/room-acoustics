# 007 Доводка UX

Проверка всех экранов на эмуляции iPhone (24 экрана и состояния, светлая и тёмная тема): сценарии, размеры
элементов, контраст, тексты. Автоматические проверки: зона касания ≥ 44 pt, контраст WCAG AA, шрифт полей ≥ 16 px,
подписи полей, ширина экрана.

## Найдено и исправлено

### Критичное
- **Выбранный вариант расстановки не становился текущим.** «Настройка», «Обзор», 3D и замер считались для исходной
  расстановки, пока не нажать «Открыть в ручном режиме». Теперь, если своей расстановки ещё нет, лучший вариант
  сразу становится текущим; у других вариантов — кнопка «Использовать этот вариант», у текущего — отметка и переход
  «Дальше: «Настройка»».
- **«Предложить план» обработки тихо включал её во всех расчётах** (оценка, подбор, карты — как будто ловушки уже
  стоят). Теперь план только предлагается (сравнение «без → с» видно сразу); если включить «Учесть в расчёте»,
  на всех экранах сверху видна полоска с кнопкой «Без обработки».
- **Safari на iPhone увеличивал страницу при касании любого списка выбора** (шрифт 15,5 px) и полей экспорта.
  Теперь 16 px.

### Заметное
- Первый запуск: вместо пустого плана — карточка «С чего начать» (выбрать файл скана / ввести размеры).
- После «Применить размеры» — следующий шаг: «Дальше: расстановка» и «Посмотреть план».
- 3D: модель сразу под пояснением, частоты — 12 первых и «Ещё N» (раньше 3D было под 28 кнопками частот).
- Кнопка «Подобрать расстановку» видна, пока заполняются настройки.
- Зоны касания 44 pt: переключатели, маленькие кнопки, раскрывашки, вкладки вариантов; у кнопок ▶, частот и ползунка
  среза — увеличенная невидимая зона.
- Новый файл скана больше не показывается рядом со старым превью; при ошибке видна только ошибка.
- Настройка: элементы плана обработки свёрнуты в строку с описанием (раскрываются по «Место и размеры»);
  экспорт фильтров — один формат за раз (Equalizer APO / REW / miniDSP). Экран короче на 3 высоты экрана.

### Тексты и мелочи
- «СКО отклонения…» → «на сколько децибел бас в среднем отклоняется от ровной линии».
- Панель зон: «Препятствия и проёмы» (путалась с «Проёмами и смежными помещениями») → «Где нельзя ставить колонки».
- Моды: «1 0 0 (34,3 Гц)» вместо «1,0,0 (34.3 Гц)»; везде «тангенциальная».
- Материалы на телефоне — в одну колонку (названия не обрезаются); таблица RT60 помещается без прокрутки.
- Кнопки «+ Коридор / + Проём / + Ниша / + Окно / + Дверь» в одну строку (для экранного диктора — «Добавить …»).
- Длинные заголовки разделов не переносятся; контраст зелёных заметок и подписи ползунка среза — по AA.
