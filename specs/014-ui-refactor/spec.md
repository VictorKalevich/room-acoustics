# 014 — Навигация и модули интерфейса

Статус: реализовано; ретроспективная сверка 2026-11-10.
Основание: [D01–D02](../decisions.md). Архитектура: [docs/ui-refactor](../../docs/ui-refactor.md).

## Требования

- FR-1401: четыре свободно доступных раздела — Комната, Анализ, Расстановка, Настройка.
  Измерения и Место для записи доступны из меню; функции не удаляются.
- FR-1402: общая система и цель расстановки расположены над авто/ручным режимами.
  Общие данные Project, замеры, история и зависимости сохраняются.
- FR-1403: навигация помнит подразделы/прокрутку в сеансе, поддерживает старые адреса
  и историю браузера. Переход из проблемы обзора открывает соответствующий инструмент.
- FR-1404: посещённые инструменты сохраняют локальное состояние при переходах;
  изменение зависимых входов сбрасывает устаревшие EQ/саб-результаты, другой проект
  сбрасывает локальный контекст. Просмотр варианта отличим от применения.
- FR-1405: скрытые измерения останавливают микрофон; поздний ответ разрешения не
  запускает скрытую запись. EQ-прослушивание останавливается при уходе.
- FR-1406: использовать общие компоненты навигации, состояния расчёта и сохранения вида.
  Узкий экран не имеет горизонтального переполнения, группы комнаты сворачиваются.
- FR-1407: на этом этапе не менять core/state/workers/scan/audio, формулы и формат проекта.

## Приёмка

1. После смены режима расстановки система и цель остаются общими; изменение комнаты
   обновляет связанные инструменты, импорт REW доступен сравнению и EQ.
2. Старые #modes/#field/#manual открывают нужные подразделы; назад/вперёд работают.
3. Возврат в EQ сохраняет результат без изменения входов; смена входов/проекта
   не показывает прежний результат как актуальный.
4. Уход из измерений и позднее разрешение доступа не оставляют скрытую запись.
5. Проверка ширин 320/393/1280 px не выявляет горизонтального переполнения.
