# 043 — Проверка

## Автоматически

```powershell
npx vitest run tests/core/houseCurve.test.ts tests/state/project.test.ts
npm test; npm run lint; npm run build
$env:PLAYWRIGHT_CHROMIUM_CHANNEL='chrome'; npm run e2e
```

- `tests/core/houseCurve.test.ts`: форма кривой (≥ 97 % ниже 40 Гц, половина на 105 Гц, ≤ 10 % выше 200 Гц,
  монотонность); чтение значения; цель оценки = «Ровно» + подъём; согласованность автоподбора, карт и фильтров
  сабвуферов; автоподбор по цели с подъёмом лучше подбора «Ровно» по этой цели (4 × 3,2 м) и не хуже (5 × 4 м с
  сабвуфером); результат помнит подъём; фильтры сабвуферов; «Подобрать настройки» в углу (−6 дБ при «Ровно», выше при
  +6) и пояснения; эквалайзер не срезает широкий подъём низа при +6; сравнение замеров по кривой подъёма.
- `tests/state/project.test.ts`, «043: подъём низа в файле проекта»: 3 / 6 / 9 сохраняются и читаются, «Ровно» не
  пишется, неверные значения — «Ровно».
- `tests/e2e/app.spec.ts`, «043: подъём низа…»: выбор «+6 дБ», сводка блока, устаревший результат с прежней подписью
  пунктира, новый подбор с подписью «цель: подъём низа +6 дБ», строки на «Сабвуфере» и «Эквалайзере», сохранение после
  перезагрузки, «Ровно» убирает поле.

## Вручную в приложении

1. «Расстановка» → «Система и цель подбора» → «Цель подбора»: под «Что искать» — «Подъём низа», выбрано «Ровно».
2. Подобрать расстановку; выбрать «+6 дБ»: результат помечен устаревшим, подпись пунктира — «без комнаты». «Пересчитать»:
   пунктир поднимается ниже ~100 Гц, подпись — «цель: подъём низа +6 дБ».
3. «Настройка» → «Сабвуфер»: строка «Цель — подъём низа +6 дБ…»; «Подобрать настройки» — уровень сабвуфера обычно выше,
   чем при «Ровно». «Эквалайзер»: та же строка; фильтры не срезают подъём низа.
4. «Отчёт»: строка о цели. Сравнение замеров: неровность — относительно подъёма.
5. Перезагрузить страницу: выбрано «+6 дБ». Выбрать «Ровно» — всё как до 043.
