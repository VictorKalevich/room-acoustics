# 043 — Данные

## Ограничения проекта — `constraints.houseCurve`

Необязательное поле, тип `HouseRise = 3 | 6 | 9` (дБ). Версия формата файла не меняется.

| Значение в файле или хранилище | При открытии | В интерфейсе |
| --- | --- | --- |
| нет поля | нет поля | «Ровно» |
| 3, 6, 9 (число) | то же | «+3 дБ», «+6 дБ», «+9 дБ» |
| любое другое (0, 5, −3, «6», null) | нет поля (`normalizeHouseRise`) | «Ровно» |

«Ровно» в файл не пишется: проект без подъёма сохраняется так же, как до 043.

## Результат автоподбора — `result.houseCurve`

Необязательное поле `PlacementResult`: подъём, с которым посчитан результат. Нет — ровная цель (и у результатов до
043). Нужно только для подписи пунктира у устаревшего результата; при чтении проверяется тем же `normalizeHouseRise`
(неверное — «без комнаты»). Проверка формы результата (`cleanResult`) поле не требует.

## Целевая кривая (вычисляется, не хранится)

`target(f) = номинальные фильтры системы (как до 043) + houseDb(rise, f)`.

`houseDb(rise, f)` — АЧХ аналоговой полки второго порядка: H(s) = A·(s² + √A/Q·s + A) / (A·s² + √A/Q·s + 1),
s = j·f/105, A = 10^(rise/40), Q = 1/√2; без подъёма — 0. Значения — [research R1](./research.md).

| Где | Кривая |
| --- | --- |
| Оценка расстановки, пунктир графиков, автоподбор, карты, «Подобрать настройки», «Подобрать фильтры сабвуферов», эквалайзер, «Обзор», ловушки, «Отчёт» | номинальная + подъём |
| Предотбор колонок в их полосе (автоподбор с сабвуферами) | номинальная кривая колонок |
| Прослушивание EQ (влияние комнаты) | номинальная |
| Сравнение замеров | только подъём |
