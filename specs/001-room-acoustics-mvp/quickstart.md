# Quickstart: проверка MVP

## Требования

Node.js 20+ и npm. Для ручной проверки — iPhone с Safari (iOS 26+).

## Запуск

```bash
npm install
npm test            # юнит-тесты ядра и распознавания (Vitest)
npm run dev         # локальный сервер разработки
npm run build       # статическая сборка в dist/
npm run preview     # просмотр сборки
npm run e2e         # сквозные тесты в эмуляции iPhone (Playwright)
```

На iPhone в одной сети с компьютером: `npm run dev -- --host` и открыть адрес из консоли
(для офлайн-режима и установки нужен HTTPS — проверяется на опубликованной версии).

## Сценарии проверки

1. **Моды (US1)**: «Комната» → ввести 5 × 4 × 2,5 → «Моды»: первые строки 34,3 / 42,9 /
   54,9 / 68,6 Гц, тип и индексы видны; 4 × 4 × 2 → предупреждение о кратных размерах.
2. **Расстановка (US2)**: «Расстановка» → 2 колонки 80–20000 Гц, 1 сабвуфер 20–80 Гц →
   «Подобрать»: ≤ 10 с, 3 варианта с оценкой и графиком; лучший лучше базового.
   Сменить сабвуфер на 20–120 Гц → оценки меняются.
3. **Скан (US3)**: загрузить `tests/fixtures/sample-room.obj` (генерируется `npm run fixtures`)
   → размеры 5,00 × 4,00 × 2,50 ± 0,05, 3D-превью и план; повреждённый файл → понятная ошибка.
4. **Материалы (US4)**: пол «Паркет» → «Ковёр толстый»: RT60 на 1–4 кГц уменьшается,
   частота Шрёдера пересчитывается; формула и допущения указаны.
5. **Проекты (US5)**: сохранить, экспортировать файл, удалить, импортировать — данные те же;
   после первого открытия опубликованной версии включить авиарежим — приложение работает.
