# Contract: файл проекта (экспорт/импорт)

Расширение `.roomacoustics.json`, UTF-8.

```json
{
  "format": "room-acoustics-project",
  "version": 1,
  "project": {
    "id": "uuid",
    "name": "Гостиная",
    "updatedAt": "2026-11-07T18:00:00Z",
    "room": { "depth": 5, "width": 4, "height": 2.5, "temperatureC": 20,
              "furnishing": "typical", "source": "manual",
              "materials": { "floor": "parquet", "ceiling": "concrete-painted",
                             "front": "plaster", "back": "plaster",
                             "left": "plaster", "right": "plaster" } },
    "sources": [ { "id": "spkL", "kind": "speaker", "fLow": 80, "fHigh": 20000, "height": 1.0 } ],
    "constraints": { "speakerMinFront": 0.2, "speakerMinSide": 0.3,
                     "listenerMinX": 1.5, "listenerMaxX": 4.4, "earHeight": 1.1,
                     "subZone": "walls", "subWallGap": 0.15 },
    "scanInfo": null,
    "result": null,
    "selectedIndex": 0
  }
}
```

Правила импорта: неизвестный `format` или `version` > 1 → понятная ошибка; отсутствующие
поля заполняются умолчаниями; значения вне допустимых диапазонов отклоняются с указанием поля.

Уточнение 021: необязательное поле `project.roomReady` (комната создана — скан или сохранённая
ручная настройка); без него признак выводится при импорте ([021](../../021-manual-room-setup/spec.md)).
Мебель, зоны, окна, двери, проёмы, ковры, шторы, коридоры и скос за стенами комнаты не отклоняют
проект, а вписываются в комнату (обрезаются или удаляются); размеры комнаты по-прежнему проверяются.

Уточнение 022: необязательные поля `current.placed` (места колонок, сабвуфера и слушателя выбраны; без него
выводится при импорте) и `room.calibration.source`, `room.calibration.leakageBefore` (по какому замеру
подстроено и герметичность до подстройки) ([022](../../022-room-flow/spec.md)).

Уточнение 026: необязательное поле `project.precision` (`high` или `max` — точность расчёта; без него —
стандартная, она в файл не пишется). Версия файла прежняя. При импорте неверный диапазон или высота отдельного
источника, не-числовые ограничения и координаты заменяются умолчаниями, пустые элементы списков и коридор,
не проходящий проверку, отбрасываются — проект открывается с остальными данными; размеры комнаты и число
источников по-прежнему проверяются ([026](../../026-calc-precision/spec.md)).
Там же: необязательные `constraints.crossover.spkLimit`, `subLimit` (пределы самой техники для подбора частоты
раздела) и `scanInfo.applied` (применённые границы скана: `rect` и `units`); неверные значения отбрасываются.

Уточнение 028: формат и версия файла прежние. При импорте и открытии сохранённого проекта проверяется и форма
полей, которые раньше переносились как есть: `result` неверной формы отбрасывается целиком (выбранный вариант —
первый, подбор предлагается заново); у `scanInfo`, вариантов расстановки (`id`, `name`, `subSettings`,
`crossoverHz`), ограничений раздела, настроек сабвуферов, проёмов, коридоров, обработки, зон, подстройки и скоса
неверный элемент списка или необязательное поле убирается, обязательное значение заменяется умолчанием. Смысл
величин не проверяется; верные данные не меняются. Полная таблица — в [028](../../028-render-failure/spec.md).
