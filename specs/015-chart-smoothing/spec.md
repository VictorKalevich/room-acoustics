# 015 — Высота микрофона и сглаживание графиков

Статус: реализовано; ретроспективная сверка 2026-11-10.
Основание: [D04–D05](../decisions.md). Метод: [docs/ui-smoothing](../../docs/ui-smoothing.md).

## Требования

- FR-1501: убрать «Сидя/стоя», оставить высоту в сантиметрах без сброса старого mouthZ.
  posture сохраняется для совместимости. Итоговая подпись «Высота микрофона» — уточнение 017.
- FR-1502: голос — исходная кривая 1/6, 1/3, 1/2; по умолчанию исходная.
  Авто/ручная расстановка — Без, 1/12, 1/6, 1/3, 1/2; по умолчанию 1/12.
- FR-1503: ползунок только по фиксированным точкам, кликабельные подписи, стрелки/Home/End.
- FR-1504: три независимые настройки localStorage ra-chart-smoothing:<screen>.
  Они переживают перезагрузку, не входят в проект и не влияют на другие экраны.
- FR-1505: отдельный психоакустический режим скрывает октавный ползунок, сохраняя его
  прежнее положение для возврата. Он не равен постоянному сглаживанию 1/3.
- FR-1506: обрабатывать только исходные массивы для отрисовки, без мутации и накопления
  сглаживания. В сравнении все кривые получают одинаковую обработку; шкала опирается
  на исходные данные. Карты, оценки, поиск, экспорт и worker не меняются.
- FR-1507: не повышать частотную детализацию. 1/48 исключено, 1/24 и голосовой 1/12
  не добавлены. Исходная 1/6 не означает несглаженный точечный спектр.

## Приёмка

1. Изменение настройки голоса не меняет авто/ручную расстановку и наоборот, включая reload.
2. Возврат из психоакустического режима восстанавливает выбранную октавную точку.
3. Смена сглаживания меняет только кривые; карта, оценки и число фоновых расчётов прежние.
4. Старый проект с нестандартной высотой (например, 1,235 м) сохраняет её при импорте.
5. Исходная кривая восстанавливается без накопленной обработки; на 320/393 px нет overflow.
