# 044 — Проверка

## Автоматически

```powershell
npx vitest run tests/core/deepBass.test.ts tests/state/project.test.ts
npm test; npm run lint; npm run build
$env:PLAYWRIGHT_CHROMIUM_CHANNEL='chrome'; npm run e2e
```

- `tests/core/deepBass.test.ts`: Баттерворт порядка 1–12 (−3,01 дБ на частоте среза, точная АЧХ, 6·N дБ на октаву,
  2-й порядок — прежний фильтр); спад по двум точкам (KRK S10.4 — 10-й порядок, −10 дБ на 27 Гц), по одной точке и
  корпусу, без паспорта, при неверной паре; план цели и частота по умолчанию; чтение из файла; оценка (спад в пределах
  допустимого — 0, глубже — растёт, пики не считаются, допуск 1 дБ выше частоты среза); строка о низе; другие цели не
  читают паспорт и поля цели; неровность и график — прежние; без сабвуферов — «Меньше провалов внизу»; согласованность
  подбора, карт и оценки варианта; подбор держит низ лучше лучшего по ровности.
- `tests/state/project.test.ts`, «044: паспорт сабвуфера и цель «Глубже низ» в файле проекта».
- `tests/e2e/app.spec.ts`, «044: глубже низ…»: выбор цели, паспорт с пустой точкой без ошибки, корпус, строка о низе,
  устаревший результат при смене частоты, сохранение после перезагрузки, пустая частота — снова по паспорту.

## Вручную в приложении

1. «Расстановка» → «Система и цель подбора» → «Цель подбора» → «Что искать»: «Глубже низ». Ниже — «Продлевать бас
   до», «Допустимый спад», «Спад сабвуфера по паспорту».
2. Ввести −3 дБ 30 Гц и −10 дБ 27 Гц: строка «Спад: 60 дБ на октаву… (по двум точкам)», «Продлевать бас до» — 27 Гц.
   Очистить −3 дБ — без ошибки, крутизна по корпусу; «Закрытый» — 12 дБ на октаву.
3. «Подобрать расстановку»: главное число — «Глубже низ», под ним «Самый низ: … дБ на 27 Гц», ниже — неровность.
4. Поставить 25 Гц: результат помечен устаревшим; «Пересчитать» — строка о 25 Гц.
5. Ручной режим: цвет карты сабвуфера и лучшие места — по цели «Глубже низ»; та же строка о низе в оценке.
6. Перезагрузить: цель, паспорт и частота на месте. Выбрать другую цель — всё как до 044.
