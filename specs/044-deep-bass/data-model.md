# 044 — Данные

## Сабвуфер — `SourceSpec.passport`

Необязательное поле сабвуфера, тип `SubPassport`. Версия формата файла не меняется. Читает его только цель «Глубже
низ»; «Диапазон» (`fLow`, `fHigh`) и все другие расчёты от него не зависят.

| Поле | Тип | При открытии файла |
| --- | --- | --- |
| `f3` | частота спада −3 дБ, Гц | число 10–200, иначе поле убирается |
| `f10` | частота спада −10 дБ, Гц | число 10–200, иначе поле убирается |
| `box` | `'ported'` (фазоинвертор) или `'sealed'` (закрытый) | из списка, иначе поле убирается («Фазоинвертор») |

Пустой паспорт (ни одного поля) не хранится. У колонок поле не хранится.

## Цель подбора — `BassObjective` с `id: 'deep'`

| Поле | Тип | При открытии файла | Нет поля |
| --- | --- | --- | --- |
| `deepHz` | частота цели, Гц | число 20–60, иначе поле убирается | по сабвуферам (FR-4404) |
| `deepDrop` | `3 \| 6 \| 10`, дБ | из списка, иначе поле убирается | 6 дБ |

Поля сохраняются при переключении на другую цель и обратно (как набор мод у цели «моды»); другие цели их не читают.

## Спад сабвуфера (вычисляется, не хранится) — `subRolloff`

Фильтр верхних частот Баттерворта: `|H(f)|² = 1 / (1 + (fc/f)^(2N))`, минимально-фазовый — произведение звеньев
2-го порядка `s² / (s² + s/Q_k + 1)`, `Q_k = 1 / (2·sin((2k − 1)·π / (2N)))`, и звена `s / (s + 1)` при нечётном N;
`s = j·f/fc`.

| Паспорт | N | fc |
| --- | --- | --- |
| f₋₃ и f₋₁₀, f₋₁₀ < f₋₃ | round(ln 9,045 / (2·ln(f₋₃/f₋₁₀))), 1…12 | f₋₁₀ · 9^(1/(2N)) |
| f₋₁₀ (или f₋₁₀ ≥ f₋₃) | закрытый — 2, фазоинвертор — 4 | f₋₁₀ · 9^(1/(2N)) |
| только f₋₃ | по корпусу | f₋₃ |
| нет | по корпусу | `fLow` («Диапазон от») |

`ln 9,045 = ln((10¹ − 1)/(10^0,3 − 1))`: отношение уровней −10 и −3 дБ.

## План цели (вычисляется) — `deepPlan(sources, objective)`

`null`, если цель не «Глубже низ» или нет сабвуферов. Иначе: спад каждого сабвуфера, `split` — наименьшая fc,
`fT` — частота цели (`deepHz` или по умолчанию), `drop` — допустимый спад.

## Показ — `SetupEval.low`, `Placement.low`

Необязательное поле, только у цели «Глубже низ»: `{ fT, drop, atT, reach }` — частота цели, допустимый спад, уровень на
частоте цели относительно обычного уровня баса (дБ, сглаживание полутоном) и самая низкая частота ниже `split`, до
которой уровень не ниже −`drop` (`null`, если уже на `split` ниже). В файле проекта не хранится: результат подбора
хранит его вместе с вариантами, при чтении поле не проверяется и не требуется.
