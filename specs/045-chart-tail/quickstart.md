```powershell
npx vitest run tests/core/chartTail.test.ts tests/state/project.test.ts tests/state/repair.test.ts
npm test; npm run lint; npm run build
$env:PLAYWRIGHT_CHROMIUM_CHANNEL='chrome'; npm run e2e
```

- `tests/core/chartTail.test.ts`: сшивка без скачка (на fLo спад по паспорту равен номинальному, ниже — форма паспорта,
  фильтры и цель на границе — прежние); граница −20 дБ (S10.4 — 23,9 Гц), не ниже 20 Гц; нет хвоста при fLo = 20 Гц;
  сетка с шагом полосы; паспорт колонок только без сабвуфера; часть кривой в полосе — ровно `response`; хвост — отклик
  комнаты с тем же сдвигом; `response` и все оценки те же, что без кривой, при всех целях, с подъёмом низа и паспортами;
  «Глубже низ» (цель без спада сабвуфера, начало по модели цели, медиана выше среза — 0, fT выше fLo, без паспорта);
  автоподбор — кривая у вариантов и базовой; волновая модель.
- `tests/state/project.test.ts`, «045: паспорт спада колонок в файле проекта»; `tests/state/repair.test.ts` — форма
  `chart` в сохранённом результате.
- `tests/e2e/app.spec.ts`, «045: график ниже полосы оценки…» и обновлённый «044: глубже низ…».

## Вручную в приложении

1. «Расстановка» → «Система и цель подбора» → «Сабвуферы»: «Нет». Под «Диапазоном» раскрыть «Спад по паспорту»:
   блок «Колонки» с −3 дБ, −10 дБ и «Корпус (колонки)». Без значений — «Спад: паспорт не указан…».
2. Ввести 55 и 40 Гц, «Закрытый»: строка «Спад: … (по двум точкам)». «Подобрать расстановку»: график начинается около
   25 Гц, полоса ниже «Диапазона от» затенена, в легенде — «не входит в оценку».
3. «Сабвуферы»: «1». Блок колонок исчезает, появляется «Сабвуфер 1». Ввести 30 и 27 Гц, «Диапазон от» сабвуфера 30:
   после пересчёта график начинается около 24 Гц.
4. «Что искать»: «Глубже низ». В «Цели подбора» — частота, допустимый спад и строка «Спад сабвуфера цель берёт из
   паспорта…». «Пересчитать»: пунктир внизу без спада сабвуфера, затенение — ниже частоты цели, под графиком —
   пояснение.
5. «Вручную»: тот же график текущей расстановки, сравнения и пробы.
6. Перезагрузить: паспорта на месте (и паспорт колонок — при сабвуфере, хоть и скрыт). «Сабвуфер», «Эквалайзер»,
   «Отчёт», сравнение замеров — графики как до 045.
