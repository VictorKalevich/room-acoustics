# 045 — Данные

## Паспорт спада — `SourceSpec.passport`

Тип `Passport` (было `SubPassport`, 044). Поля и проверка при открытии файла — прежние ([044](../044-deep-bass/data-model.md)):
`f3`, `f10` — числа 10–200 Гц, `box` — `'ported'` или `'sealed'`; неверное поле убирается, пустой паспорт не
хранится. Версия формата файла не меняется.

| Источник | Хранится | Читают |
| --- | --- | --- |
| Сабвуфер | всегда | цель «Глубже низ» (044) и график «Расстановки» ниже полосы оценки |
| Колонка | всегда (с 045; раньше убирался при открытии) | только график «Расстановки» и только в системе без сабвуфера |

Паспорт колонок один на все колонки, как «Диапазон»: интерфейс пишет одинаковый паспорт в каждую колонку. При
сабвуфере он не показывается и не действует, но хранится.

## Спад ниже полосы (вычисляется, не хранится) — `tailCurves`, `tailHighPass`

| Случай | Спад снизу на частоте f < fLo |
| --- | --- |
| паспорт не действует (нет или колонки при сабвуфере) | номинальный: `sourceHighPass` (Баттерворт 2-го порядка от «от»; у колонок при сабвуфере — LR4 на стыке) |
| паспорт действует | `butterworthHp(N, fc, f) · k`, N и fc — `passportRolloff` (044), k = `sourceHighPass(fLo) / butterworthHp(N, fc, fLo)` |
| цель «Глубже низ», сабвуфер | спад из плана цели (`deepPlan(...).curves`), без сшивки — как в оценке цели |

Граница графика `tailFloor`: наименьшая по источникам частота, где |спад| = −20 дБ (`TAIL_DB`), не ниже 20 Гц
(`TAIL_MIN_HZ`); fLo, если все источники на fLo уже тише. Сетка `tailGrid(band, from)`: f₀·q⁻ᵏ для k = 1, 2, … пока
f > from·q^¼, в начале — `from`; q — шаг сетки полосы.

## Кривая графика — `SetupEval.chart`, `Placement.chart`

Тип `ChartCurve`, необязательное поле. `evaluateSetup` заполняет его только с `chart: true` и только если есть что
показать ниже полосы (или цель «Глубже низ»); иначе поля нет, и график строится из `response`.

| Поле | Тип | Смысл |
| --- | --- | --- |
| `f` | `number[]` | частоты, Гц: хвост, затем полоса (при «Глубже низ» — сетка цели) |
| `db` | `number[]` | отклик в комнате, дБ, с тем же сдвигом, что у `response` (при «Глубже низ» — медиана отклонения выше среза = 0) |
| `target` | `number[]` | цель, дБ: сумма фильтров без комнаты и подъём низа (при «Глубже низ» — без спада сабвуферов снизу) |
| `scoredFrom` | `number` | нижняя граница оцениваемой части, Гц: fLo; при «Глубже низ» — меньшая из fT и fLo |

В сохранённом результате подбора (`project.result`) поле хранится у вариантов и базовой. При открытии проверяется форма
(`okPlacement`): `f`, `db`, `target` — списки чисел или `null`, `scoredFrom` — число; неверная форма — результат
отбрасывается целиком (FR-2801, 028). Результат до 045 — без поля, график прежний до нового подбора.

## Не меняются

`SetupEval.response`, `Placement.response`, `evalBand` (fLo, fHi), оценки и все поля результатов, кроме нового `chart`.
