# Quickstart: фича 003

```bash
npm test && npm run e2e
```

1. «Комната» → «Проёмы и смежные помещения» → «Добавить коридор»: правая стена, 0–5 м, глубина 1,2 м,
   арка 1,0–2,4 м → коридор на плане.
2. «Моды»: список «Моды системы комната + коридор» с долей энергии в комнате.
3. «Расстановка → Вручную»: карта строится по волновой модели (подпись модели у результатов).
4. Скан с коридором → вид сверху, предложены проём и коридор → «Применить».
