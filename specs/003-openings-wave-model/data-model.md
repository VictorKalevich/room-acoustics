# Data Model: фича 003

### Opening (проём наружу/в большой объём)
`id`, `wall: 'front'|'back'|'left'|'right'`, `a0 < a1` (м вдоль стены: для передней/задней — от левой стены,
для левой/правой — от передней), `height` (м от пола).

### Extension (смежное помещение, например коридор)
`id`, `name`, `wall`, `a0 < a1` (участок вдоль стены), `depth` (м за стеной), `height`,
`arch: { a0, a1, height }` (проём между комнатой и коридором, внутри участка),
`openStart`, `openEnd` (концы вдоль стены открыты), `openFar` (дальняя сторона открыта).

### Room (новые поля)
`openings: Opening[]`, `extensions: Extension[]`, `model: 'auto'|'modal'|'wave'` (по умолчанию 'auto').
