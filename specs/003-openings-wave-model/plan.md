# Implementation Plan: Проёмы, смежные помещения и волновая модель

**Branch**: `003-openings-wave-model` | **Date**: 2026-11-08 | **Spec**: [spec.md](./spec.md)

## Summary

Модель комнаты дополняется проёмами и смежными помещениями (прямоугольные блоки, примыкающие к стенам).
Прямоугольная модель учитывает проёмы как поглощение; новая волновая модель (FDTD) считает отклик по
реальному объёму «комната + коридор». Все расчёты получают отклики через общий провайдер (модальный или
волновой); волновые расчёты кэшируются в постоянном воркере, а интерфейс получает оценки асинхронно.
Разбор скана находит проёмы и коридор и даёт выбрать основную комнату. Решения — [research.md](./research.md).

## Technical Context

Стек без изменений, новых зависимостей нет. Волновое ядро — чистый TypeScript (типизированные массивы),
выполняется в воркере. Производительность: один расчёт ≤ 3 с, карта сабвуфера ≤ 10 с (SC-202/203).
