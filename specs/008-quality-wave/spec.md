# 008 Надёжность, сравнение замеров, волновая модель, CamillaDSP

Без микрофона: всё, что не требует реального замера комнаты. Проверка расчётов по реальному замеру
(сравнение модели с измерением в комнате пользователя) остаётся на потом.

## Инфраструктура
- **CI.** На каждый push: линтер, юнит-тесты, сборка, e2e на эмуляции iPhone (Chromium); при падении сохраняется
  отчёт Playwright. Отдельное задание — те же e2e в Safari (WebKit), пока не блокирует выкладку.
  Локально: `npm run e2e`, `npm run e2e:safari` (первый раз — `npx playwright install webkit`).
- **Линтер** oxlint (typescript-eslint несовместим с TypeScript 7): правила React и хуков, `npm run lint`,
  предупреждения считаются ошибками. Отключены с обоснованием: `react/immutability` (не узнаёт `useRef` из Preact),
  `require-post-message-target-origin` (у воркеров нет origin), сортировка на месте (везде — на копиях, проверено).

### Что нашёл линтер (исправлено)
- Анализатор: калибровка микрофона, загруженная во время работы, не применялась до перезапуска.
- План скана: при растяжке прямоугольника за пределы скана точки скана не сдвигались вместе с разметкой.
- Меню: обработчик Escape пересоздавался при каждой перерисовке (фокус мог прыгать).
- 3D: после смены комнаты в волновой модели выбиралась мода прежней комнаты.
- Ключи у элементов списков (93 места; у редактируемых — проёмы, окна, двери, зоны, обработка — по id).

## Битые файлы сканов
- Предел размера файла 500 МБ (понятная ошибка до чтения).
- Двоичный STL: заголовок проверяется до разбора (повреждённый заголовок мог потребовать гигабайты памяти).
- Треугольники с NaN/бесконечностью и далёкие выбросы (дальше одного габарита скана от основной массы)
  отбрасываются; пользователь видит, сколько. Коридор за аркой и ниши выбросами не считаются.
- Распознавание: гистограммы не создаются для нереальных габаритов (ошибка вместо гигабайтов памяти).
- 22 теста: пустой, неизвестный, мусорный заголовок, обрезанный STL/GLB/glTF/PLY, облако точек, только вершины,
  NaN, улетевшие точки, случайные байты под каждым расширением.

## Журнал ошибок и «Сообщить о проблеме»
- Необработанные ошибки, отказы промисов, ошибки расчётов в воркере (со стеком) и неудачные загрузки сканов
  копятся на устройстве (последние 40, одинаковые подряд не дублируются, без отправки куда-либо).
- «О приложении» → «Сообщить о проблеме»: последние ошибки, поле «Что случилось», файл отчёта (версия, браузер,
  экран, ошибки, по желанию — проект, который можно открыть в приложении).

## Код

## До и после
- У расстановки хранятся прошлые замеры (до 5). Новый замер (свип или импорт REW) отправляет прежний в историю;
  повторное сохранение того же сеанса свипа с добавленными точками — уточнение, а не новый замер.
- «Замер» и «Настройка → Замер»: график «до» и «сейчас», неровность, сильнейший пик и глубочайший провал
  (20–200 Гц, 1/12 октавы, уровни выровнены по среднему), вывод «стало ровнее на N дБ».
- Формат файла проекта 5 (история замеров; битые записи при открытии отбрасываются).

## Волновая модель: скорость
- Шаг на плотной сетке: внутренние узлы — отрезками с постоянными смещениями, без таблиц соседей
  и коэффициентов; граничные — списком. Результат совпадает с прежней схемой бит в бит (тест).
- Поле на частотах: ДПФ копит отсчёты блоками по 8 (суммы в double) — точнее и вдвое меньше обращений к памяти.

| Расчёт (fMax 200 Гц) | было | теперь, β постоянная | теперь, β(f) |
|---|---|---|---|
| Временные ряды, комната 5×4×2,5 (10,8 тыс. узлов) | 0,45 с | 0,30 с | 0,47 с |
| Временные ряды, с коридором (17,3 тыс.) | 0,67 с | 0,51 с | 0,76 с |
| Поле на 24 частотах, комната | 1,42 с | 0,69 с | 0,89 с |
| Поле на 24 частотах, с коридором | 2,21 с | 1,30 с | 1,48 с |

## Волновая модель: частотно-зависимые границы
Раньше у каждой грани была постоянная β по α, усреднённому в полосе 40–160 Гц: затухание мод волновой модели
было одинаковым на всех частотах, хотя у материалов α меняется (панели: 0,08 на 63 Гц → 0,75 на 250 Гц).

Теперь (модель по умолчанию `fd`) проводимость грани β(s) = β∞ + Σ последовательных RLC-ветвей (пассивные
резонаторы на центрах 16–362 Гц через пол-октавы, Q = 1,6), подобранная так, чтобы диффузное поглощение
(интеграл Пари с комплексной β) совпадало с табличным α(f) в полосе 20 Гц … 1,3·fMax. Подбор — точные
неотрицательные наименьшие квадраты с поправкой на мнимую часть; лишние ветви убираются, пока α в допуске
(0,003 + 6 %): у бетона и штукатурки ветвей нет вовсе. Ветви одной частоты на разных гранях узла складываются.
Дискретизация — трапеция на двойном шаге с неявной связью с давлением (пассивна при любых R, L, C > 0),
частоты ветвей предыскажены под схему. Постоянная β осталась моделью `fi`.

**Проверка** (затухание осевых мод по глубине; пара стен — материал, остальное — бетон; источник и приёмник
на средних плоскостях; T60 волновой модели / T60 модальной модели):

| Стены | 32 Гц | 65 Гц | 97 Гц | 162 Гц | разброс по частоте |
|---|---|---|---|---|---|
| акустические панели, β постоянная | 0,38 | 0,41 | 0,80 | 1,81 | ±87 % |
| акустические панели, β(f) | 0,87 | 0,83 | 0,87 | 0,71 | ±9 % |
| толстый ковёр, β постоянная | 0,55 | 0,57 | 0,90 | 1,81 | ±62 % |
| толстый ковёр, β(f) | 0,94 | 0,91 | 0,97 | 0,87 | ±4 % |
| гипсокартон, β постоянная | 0,81 | 0,82 | 0,83 | 0,67 | ±10 % |
| гипсокартон, β(f) | 0,75 | 0,76 | 0,76 | 0,82 | ±4 % |

С постоянной β T60 почти не зависит от частоты (панели: 1,64–1,70 с при 4,3 → 0,94 с у модальной модели).
С β(f) ход по частоте совпадает. Расчёт 10 с — без роста (устойчивость), поздний «пол» −82…−92 дБ такой же,
как с постоянной β (остаток импульса источника около 0 Гц).

**Ограничение, найденное проверкой.** Там, где поглощение заметное (α ≈ 0,3 и выше), волновая модель затухает
на 15–30 % быстрее модальной — и с β(f), и с постоянной β. Это свойство модальной формулы (возмущение первого
порядка занижает затухание при больших α, как формула Сэбина против Эйринга), а не волновой модели. Поправка
модальной модели изменит калибровки — отдельная задача; её стоит делать вместе с проверкой по реальному замеру.

## CamillaDSP
«Настройка → Эквалайзер → Экспорт → Camilla»: разделы `mixers`, `filters`, `pipeline` для CamillaDSP 3 —
микшер стерео → колонки + сабвуферы (сабвуфер — сумма L+R по −6 дБ), эквалайзер комнаты на все выходы,
задержка (с дробными отсчётами), уровень и полярность каждого сабвуфера, его PEQ и all-pass; по желанию —
раздел частот LR4. Фаза, которую CamillaDSP сделать не может (не 0/180°), — пояснением «ручкой на сабвуфере».
Подходит, когда у сабвуфера нет своей задержки: её делает CamillaDSP.
