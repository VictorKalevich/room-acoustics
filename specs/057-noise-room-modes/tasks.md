## Тесты

Unit (Vitest):

- `tests/core/noiseModes.test.ts` (14):
  - снимок равен списку `computeModes` без пересчёта, признак приближения (скос, волновая модель), `sameRoom` по размерам и температуре;
  - отказ на неверной версии, размере, температуре, типе, индексе, порядке, f > fMax, признаке;
  - маркеры: диапазон и типы, предел 24 с приоритетом осевых и сортировкой, совпадение < 0,5 %;
  - пики: тон в шуме — в пределах бина, мгновенный спектр отвергается; белый шум 30 с (Z и A) — пиков нет; 44,1 кГц; пустой диапазон;
  - допуск 3 % + шаг, порядок кандидатов, отсутствие кандидатов вдали;
  - тон на осевой моде находит её, тон вне мод — нет;
  - запись: снимок проходит проверку и переносится schema 4, записи 056 без снимка действительны, снимок без связи и повреждённый снимок отвергаются (в том числе при импорте).
- `tests/ui/noise-capture.test.ts` (+3):
  - журнал mute/unmute/context/devicechange без идентификаторов, devicechange останавливает захват, после закрытия записей нет;
  - установленное приложение: `display-mode: standalone` и `navigator.standalone`;
  - простой вход старых инструментов — без журнала и слушателей.

E2E `tests/e2e/noise-modes.spec.ts`:

- **«моды на живом спектре…»** (Chromium; WebKit — пропуск без виртуального входа):
  - выкл. по умолчанию;
  - только осевые, строка источника, 20–250 Гц, «Все типы» → 24 линии;
  - подробности и выделение;
  - пики: подсказка для «Сейчас», условия поиска для сеанса, предупреждения;
  - 320 px;
  - связь и сохранение без изменения черновика проекта;
  - смена глубины → снимок и предупреждение на живом экране и в записи;
  - «Новый проект» → связь недоступна, моды по снимку проекта измерения.
- **«записи истории…»** (Chromium и WebKit):
  - импорт трёх файлов schema 4;
  - снимок другого проекта: источник, без предупреждения, пик тона 34 Гц с возможным соответствием осевой (1, 0, 0);

  - запись без проекта → поля мод нет;

- **«смена входа без профиля каталога…»** (Chromium; WebKit — пропуск):
