# 042 — Данные

Формат проекта не меняется: новых полей нет, герметичность — прежнее `room.leakage`
(`'sealed' | 'typical' | 'door' | 'open'`, по умолчанию `'typical'`).

## Утечка в волновой модели (вычисляется, не хранится)

| Герметичность | f утечки (`LEAK_HZ`) | δ утечки = π·f, 1/с |
| --- | --- | --- |
| Закрыта наглухо | 0 | 0 — утечки нет, схема прежняя |
| Обычная, двери закрыты | 8 Гц | 25,1 |
| Открытая дверь | 25 Гц | 78,5 |
| Открытая планировка | 45 Гц | 141,4 |

Герметичность входит в ключ кэша волновых расчётов (`geometryKey`): её смена пересчитывает отклик, «Поле 3D» и моды
системы.

## Подстройка по замеру — `room.calibration.model`

| Сохранённая версия | Расчёт | Герметичность | При открытии проекта |
| --- | --- | --- | --- |
| 5 | любой | любая | сохраняется |
| 4 | прямоугольная модель | любая | сохраняется, версия становится 5 |
| 4 | волновая модель | «Закрыта наглухо» | сохраняется, версия становится 5 |
| 4 | волновая модель | остальные | сбрасывается (`calibration = null`) |
| 3 | — | — | сначала перенос 041 (нет открытых сторон → 4, иначе сброс), затем строки для версии 4 |
| 2 и раньше, нет версии | любой | любая | сбрасывается (как прежде) |

Волновая модель — как в расчёте (`isWave`): выбрана явно или в режиме «Авто» есть смежное помещение или скос.
«Подстроить модель» записывает версию 5.
