# 042 — Проверка

## Автоматически

```powershell
npx vitest run tests/core/fdtd.test.ts tests/core/fdtd-fast.test.ts tests/state/project.test.ts
npm test; npm run lint; npm run build
$env:PLAYWRIGHT_CHROMIUM_CHANNEL='chrome'; npm run e2e
```

- `tests/core/fdtd.test.ts`, «042: герметичность в волновой модели»: скорость затухания среднего давления (спектрально,
  ±5 %); в закрытой комнате меняется только однородная составляющая (остаток ≤ 1 %, моды ± 0,1 Гц); ниже 30 Гц
  изменение отклика от герметичности как в прямоугольной модели (±1 дБ); устойчивость с утечкой.
- `tests/core/fdtd-fast.test.ts`: быстрый шаг «наглухо» — бит в бит с исходной схемой; с утечкой — со схемой, где
  поправка прибавляется ко всем узлам (≤ 10⁻⁵ от максимума).
- `tests/state/project.test.ts`: перенос подстройки версий 3 и 4 (таблица — [data-model.md](./data-model.md)).

## Вручную в приложении

1. Комната с коридором (или «Модель расчёта: волновая»), герметичность «Закрыта наглухо»: запомнить АЧХ у слушателя
   на «Анализе» ниже 30 Гц.
2. Выбрать «Открытая дверь»: волновая модель считается заново, самый низкий бас (15–25 Гц) ниже на несколько дБ,
   выше 40 Гц меняются в основном провалы.
3. Проект с подстройкой, сохранённый до 042, в волновой модели с герметичностью не «наглухо»: после открытия
   подстройки нет, «Подстроить модель» доступна; в прямоугольной модели подстройка на месте.
