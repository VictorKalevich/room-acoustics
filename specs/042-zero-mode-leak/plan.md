# Implementation Plan: 042 — Герметичность комнаты в волновой модели

**Branch**: `042-zero-mode-leak` | **Date**: 2026-11-16 | **Spec**: [spec.md](./spec.md)

## Summary

В схему волновой модели добавляется утечка однородной составляющей давления: после каждого шага среднее давление по
всем воздушным узлам получает затухание p̄'' + 2δ·p̄' (центральная разность, как у границ), δ = π·f утечки из
`LEAK_HZ` прямоугольной модели. Поправка одинакова во всех узлах и копится общим смещением, которое внутренние узлы
переносят сами, а граничные — с поправкой; раз в 64 шага смещение переносится в массивы. Сумма давлений считается в
цикле шага. «Наглухо» — схема без изменений. Версия модели затухания — 5; подстройка сбрасывается только у волновой
модели с утечкой. Решения и числа — [research.md](./research.md).

**Primary Dependencies**: нет новых; ядро — чистые функции `src/core`.

**Storage**: формат проекта прежний; меняется только номер версии в `room.calibration.model` (см. [data-model.md](./data-model.md)).

**Testing**: Vitest (unit), Playwright (сквозные сценарии, Chrome; WebKit — в CI, не блокирует).

**Target Platform**: браузер, PWA на iPhone; волновая модель — в воркере.

**Project Type**: клиентское веб-приложение.

**Performance Goals**: время волнового расчёта с утечкой — не больше +10 % (FR-4208): без отдельных проходов по всем
узлам на каждом шаге.

**Constraints**: при «наглухо» числа бит в бит прежние; схема устойчива; остальные моды закрытой системы не меняются.

**Scale/Scope**: `src/core/fdtd.ts`, `src/core/types.ts`, `src/state/storage.ts`, пояснение в `src/core/measure.ts`,
тесты ядра и состояния; интерфейс не меняется.
