# 041 — Данные

Формат проекта не меняется: новых полей нет, у смежного помещения (`Extension`) прежние `openStart`, `openEnd`,
`openFar`, `a0`, `a1`, `depth`, `height`.

## Площадь открытой стороны (вычисляется, не хранится)

| Сторона | Площадь |
| --- | --- |
| Начало и конец (`openStart`, `openEnd`) — торцы вдоль стены | `depth × height` (сечение помещения) |
| Дальняя сторона (`openFar`) | `(a1 − a0) × height` |

## Подстройка по замеру — `room.calibration.model`

| Сохранённая версия | Есть открытая сторона смежного помещения | При открытии проекта |
| --- | --- | --- |
| 4 | любая | сохраняется |
| 3 | нет | сохраняется, версия становится 4 |
| 3 | да | сбрасывается (`calibration = null`) |
| 2 и раньше, нет версии | любая | сбрасывается (как прежде) |

«Подстроить модель» записывает версию 4.
