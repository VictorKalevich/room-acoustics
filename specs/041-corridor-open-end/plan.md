# Implementation Plan: 041 — Открытый конец коридора отражает бас

**Branch**: `041-corridor-open-end` | **Date**: 2026-11-16 | **Spec**: [spec.md](./spec.md)

## Summary

Открытая сторона смежного помещения в волновой модели получает комплексную проводимость излучения проёма (поршень в
экране) вместо безэховой границы ρc. В схеме с β(f) она задаётся постоянной частью, индуктивной ветвью (масса воздуха)
и пассивными ветвями RLC, подобранными по коэффициенту отражения; в схеме с постоянной β — активной частью в полосе.
Версия модели затухания — 4; подстройка по замеру сбрасывается только в комнатах с открытой стороной. Решения и числа —
[research.md](./research.md).

## Technical Context

**Target Platform**: браузер, PWA на iPhone; волновая модель — в воркере.

**Project Type**: клиентское веб-приложение.

**Performance Goals**: время волнового расчёта не растёт заметно: подбор проводимости — доли миллисекунды на площадь,
ветвей у открытой стороны — сколько нужно для допуска (прореживание, как у материалов).

**Constraints**: схема остаётся пассивной (устойчивой); комнаты без открытых сторон считаются бит в бит как прежде.

**Scale/Scope**: `src/core/paris.ts`, `src/core/admittance.ts`, `src/core/fdtd.ts`, `src/core/types.ts`,
`src/state/storage.ts`, тесты ядра и состояния; интерфейс не меняется.
