# 041 — Как проверить

Unit-тесты — из PowerShell в корне репозитория.

1. Проводимость и подбор: `npx vitest run tests/core/paris.test.ts tests/core/admittance.test.ts` — масса воздуха на
   басу и ρc на высоких; |Δr| ≤ 0,03 для площадей 0,3–40 м² при fMax 130, 200 и 320 Гц; ветви пассивны.
2. Волновая модель: `npx vitest run tests/core/fdtd.test.ts` — труба «закрыто — открыто» даёт резонансы одномерной
   теории (≤ 3 %), граница ρc их не даёт; открытые стороны устойчивы с подстройкой 0,4 и 2,5.
3. Подстройка: `npx vitest run tests/state/project.test.ts` — сброс только при открытой стороне.
4. Всё вместе: `npm test`, `npm run lint`, `npm run build`,
   `$env:PLAYWRIGHT_CHROMIUM_CHANNEL='chrome'; npm run e2e`.

В приложении: «Комната» → «Проёмы и смежные помещения» → коридор, «Конец коридора открыт». Моды системы и отклик
пересчитываются; у коридора с открытым концом T60 на басу больше, чем было (числа — в [research.md](./research.md), R6).
