# 032 — Удаление неиспользуемых файлов

Статус: в работе с 2026-11-15. Основание: [D25](../decisions.md), шаг 5
[плана рефакторинга](../../docs/refactoring-roadmap.md) ([описание шага](../../docs/refactoring/step-5-dead-code.md)).
Удаляет файлы-переэкспорты, оставшиеся на прежних путях после переносов [018](../018-design-system/spec.md),
[022](../022-room-flow/spec.md) и [024](../024-projects-menu/spec.md), и приводит документы к действующим путям.
Поведение, внешний вид, формат файла проекта и ядро не меняются.

## Задача владельца

Команда владельца на шаг 5 плана: файлы-ссылки на прежние пути никто не импортирует, но они попадают в поиск и
подсказки и создают впечатление двух мест для одного компонента. Их нужно удалить, а документы текущего состояния —
привести к действующим путям.

## Требования

- FR-3201: семь файлов из таблицы удалены. Других изменений в `src`, `tests` и `scripts` нет.
- FR-3202: документы текущего состояния (`docs/design-system.md`, `docs/ui-refactor.md`, `specs/current-state.md`)
  называют действующие пути и не упоминают удалённые.
- FR-3203: в исторических спецификациях ссылки на удалённые файлы заменены действующими (017, 021), утверждения о
  сохранённых переэкспортах (018, 024) оставлены как история этапа с пометкой об удалении в 032.
- FR-3204: без изменений — видимое поведение и внешний вид, состав сборки, правило `design:check` о прежних путях
  (остаётся защитой от возврата переэкспортов), `deploy/github-pages.yml` (границы шага), ядро, формат файла проекта.

## Приёмка

1. Файлов нет; `npm run build`, `npm run lint` (включая `design:check`), unit- и e2e-тесты проходят без правок.
2. Поиск по репозиторию не находит ссылок на удалённые пути в документах текущего состояния.
