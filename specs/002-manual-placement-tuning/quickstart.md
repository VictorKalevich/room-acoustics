# Quickstart: проверка фичи 002

```bash
npm test && npm run fixtures && npm run e2e
```

1. **Карта слушателя**: «Расстановка → Вручную» → «Место слушателя»: карта ≤ 3 с, 3 точки, «Сесть сюда».
2. **Карта сабвуфера**: «Место сабвуфера»: карта, «Поставить сюда»; с двумя сабвуферами второй неподвижен.
3. **Настройка**: сабвуфер «без задержки, фаза 0/180» → «Подобрать»: только 0°/180°, задержка 0; «Применить».
4. **Места**: 3 места, шаг 0,6 м → на плане три точки, оценки по трём местам.
5. **EQ**: «Настройка → Эквалайзер»: только срезы, кривая после EQ, копирование для Equalizer APO/REW/miniDSP.
6. **Обработка**: точки отражений на стенах плана и списком; пики с рекомендациями.
7. **Зоны**: зона на углу → сабвуфер не предлагается в ней; герметичность меняет АЧХ ниже 30 Гц.
8. **REW**: загрузить экспорт REW → наложение, расхождение; «Подстроить модель» уменьшает расхождение.
9. **Варианты**: сохранить два, сравнить — две кривые на графике.
