# Сглаживание графиков и высота микрофона

Экран «Место для записи» содержит поле «Высота рта / микрофона» в сантиметрах.
Переключатель «Сидя/стоя» удалён из интерфейса. Сохранённая высота старых проектов
сохраняется; поле posture остаётся в формате проекта для совместимости.

## Настройки отображения

| Экран | Октавные режимы | Начальное значение |
| --- | --- | --- |
| Место для записи | Исходная кривая 1/6, 1/3, 1/2 | Исходная кривая 1/6 |
| Автоподбор расстановки | Без дополнительного сглаживания, 1/12, 1/6, 1/3, 1/2 | 1/12 |
| Ручная расстановка | Без дополнительного сглаживания, 1/12, 1/6, 1/3, 1/2 | 1/12 |

У каждого экрана свой ключ localStorage `ra-chart-smoothing:<screen>`, включающий режим
обработки и положение ползунка. Смена экрана или перезагрузка не сбрасывают выбор.
Автоматический и ручной режимы также независимы. Переключение в психоакустический
режим сохраняет прежнее положение октавного ползунка. Настройки относятся к экрану
на этом устройстве, не записываются в проект и не меняют другие графики приложения.

Пользователь может перетаскивать ползунок по фиксированным положениям, нажимать подписи
или использовать стрелки/Home/End с клавиатуры. В сравнении все кривые получают одну
обработку; вертикальная шкала остаётся привязана к исходным данным.

## Границы расчётов

Код `src/core`, `src/state` и `src/workers` не менялся. Карты, подбор, оценки,
частотные сетки и экспорт исходных данных используют прежние алгоритмы.
Перемещение ползунка не запускает worker: обрабатываются только готовые массивы
для изображения. Исходные массивы не изменяются; сглаживание каждый раз применяется
к ним, а не к ранее сглаженной кривой.

У вокала исходная кривая уже усреднена приблизительно по 1/6 октавы. Позиция «1/6»
отображает именно её без повторной обработки. Более широкие режимы дополнительно
сглаживают готовые данные. Отсутствующие мелкие детали не восстанавливаются.

## Метод обработки графика

`src/ui/chartSmoothing.ts` выполняет гауссово усреднение доступных отсчётов
по логарифму частоты. Обозначенная доля октавы задаёт ширину гауссова окна
на половине максимума (FWHM); окно обрезано на трёх стандартных отклонениях.
В октавном режиме усредняется мощность, в психоакустическом — куб амплитуды.
Локальная ширина частотной ячейки учитывается в весе отсчёта.

Психоакустический режим использует идею REW: окно 1/3 октавы до 100 Гц,
плавное уменьшение по логарифму частоты до 1/6 на 1 кГц, затем 1/6.
Кубическое среднее придаёт больший вес пикам. Это приближённая обработка доступной
кривой, а не точное воспроизведение алгоритма REW, который использует IIR-фильтры.
Источник: https://www.roomeqwizard.com/help/help_en-GB/html/graph.html

Психоакустическая обработка помогает рассмотреть тональный баланс, но не моделирует
полное восприятие слухом, эхо или время затухания комнаты.

## Проверки

Unit-тесты: постоянный уровень, инвариантность к сдвигу уровня, уменьшение узких пиков,
особенность кубического среднего, неизменность исходных массивов и проверка настроек.
Браузерные тесты в Chromium и WebKit: независимость трёх экранов, сохранение после
перезагрузки, восстановление октавного режима, неизменность карты/оценки/числа фоновых
задач, возврат исходной кривой, ширина 320/393 px и импорт старого проекта с высотой рта.
