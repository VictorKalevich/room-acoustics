# Дизайн-система Acoustic Lab (Room Acoustics v2)

Утверждена владельцем для v2 ([059](../specs/059-v2-foundation/spec.md), [D58](../specs/decisions.md#d58-room-acoustics-v20-утверждённая-спецификация-изоляция-и-первый-пакет--059)). Минималистичный технический интерфейс. Это изолированная система только для `src/v2`. Действующий интерфейс использует [legacy-дизайн-систему](design-system.md) на Golos Text; её внедрение Acoustic Lab не меняет.

## Состояние реализации

Реализовано 27.11.2026 (V2-011–V2-015):

- **Токены** — `src/v2/design-system/tokens.css`, префикс `--al-`: утверждённые цвета обеих тем, цвета объектов плана, производные оттенки через `color-mix` (без новых литералов), шрифт, шкала текста, отступы 4–32, радиусы 8/12/16, высота кнопок 48 px (малая — 36 px), сенсорная цель 44 px, раскладка, анимация, слои.
- **Темы** — `src/v2/design-system/theme.ts`: без выбора — по системе (`prefers-color-scheme`), явный выбор — `data-theme` на `<html>`. Выбор хранится в `localStorage` под ключом `ra2.theme` и применяется до первой отрисовки (R12); системная тема ключ удаляет.
- **Стили** — `base.css` (основа, текстовые стили, раскладка), `controls.css`, `surfaces.css`, `data.css`, `layout.css`, `screens.css`; вход — `src/v2/app/styles.css`.
- **Компоненты** — `src/v2/design-system/index.ts`: кнопки, поля (текст, число с единицей и запятой, выбор, ползунок), переключатель, флажок, сегменты, вкладки, метки вида результата, статус расчёта, сообщения, диалоги, шторка, уведомления, пустое состояние, загрузка, ошибка, метрики, таблицы, графики (частотная характеристика, столбцы), легенды, план помещения (сверху, сбоку, спереди), навигация, значки.
- **Реестр и каталог** — `src/v2/design-system/registry.ts`; каталог открывается по адресу `#/catalog` оболочки v2.
- **Блоки экранов** (V2-016–V2-020, `screens.css`): выбор карточкой `al-choice` (радиокнопка внутри карточки), плитки разделов и инструментов `al-tile` (вся плитка — ссылка, кнопки поверх), строка списка с переносом действий `al-list__item--wrap`. Подпись пункта нижней панели может быть короче (`NavItem.short`). Поле числа сообщает о прохождении проверки (`onValidity`), заголовок пустого состояния — `h2`.
- **Редактор модели** (V2-021–V2-025): план привязывает перетаскивание к сетке (`PlanView.snapStep`; клавиши двигают на 5 и 25 см независимо от привязки), подпись точечного объекта у верхней стены переносится под него; текстовое поле применяет значение по выходу из поля или Enter (`TextField.onCommit`); строка поля с кнопками выравнивается по низу (`al-row--bottom`); выбранная строка списка объектов — кнопка с `aria-pressed="true"` и фоном акцента; сегменты, значение которых вне списка (произвольная схема системы), остаются доступными с клавиатуры.
- **Проверка** — `npm run design:check`: токены, типографика и отступы раздельно для legacy и v2; публичные модули — каждой системы свои; каждый класс `al-…` из разметки v2 определён в стилях. Тесты — `tests/v2/design-system.test.ts` (совпадение с таблицей ниже, одинаковые блоки тёмной темы, контраст, полнота реестра) и `tests/v2/e2e/catalog.spec.ts`.

Ограничения: `color-mix` и `dvh` требуют Safari 16.2+ (iOS 16.2+) — на более старых iPhone производные оттенки не отображаются. Проверено в Chromium и эмуляции iPhone в Chromium; WebKit и физический iPhone — в визуальной и физической приёмке (V2-057, V2-059).

## Шрифт

Inter Variable — пакет `@fontsource-variable/inter` (лицензия SIL OFL 1.1), файлы шрифта собираются вместе с приложением и работают без сети. Подмножества выбираются браузером по `unicode-range`: для русского и английского загружаются только латиница и кириллица (R10). Шкала текста (R11): подпись 12, вспомогательный 14, основной 16, заголовок блока 18, заголовок диалога 22, заголовок страницы 28, значение метрики 32 px.

## Размеры

- Базовые отступы: 4, 8, 12, 16, 24, 32 px.
- Базовые радиусы: 8, 12, 16 px.
- Высота основных кнопок: 48 px.

## Правила

- Поддерживаются светлая, тёмная и системная темы.
- В компонентах используются семантические CSS-переменные, а не произвольные цвета.
- Единые компоненты: кнопки; числовые поля; поля выбора; переключатели; карточки метрик; графики; таблицы; статусы расчётов; вкладки; навигация; диалоги подтверждения; панели свойств; планы помещения; легенды; уведомления; состояния загрузки и ошибок.
- Измеренные и расчётные данные различаются не только цветом: ещё подписью, начертанием линии или маркером.
- Учитываются доступность, клавиатурная навигация, контрастность, touch-управление и safe-area на iPhone.
- Проверяются ширины 320, 390 и 1440 px и промежуточные размеры. Макеты не делаются фиксированными под эти размеры.
